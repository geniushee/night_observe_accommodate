# 🌌 Starlight Stay (대한민국 광공해 지도 & 별빛 숙소)

2025 최신 광공해(VIIRS) 지도를 네이버 지도에 오버레이하여 어두운 밤하늘 지역을 탐색하고, 청정 숙소 100선 예약 및 모바일 기반 밤하늘 관측일지를 기록하는 웹 애플리케이션입니다.

---

## 📌 주요 기능
1. **VIIRS 2025 광공해 오버레이:** 네이버 지도 위에 최신 밤하늘 밝기 래스터 지도 표출 및 실시간 투명도 조절
2. **청정 숙소 100선 지도 표기:** 밤하늘 관측에 최적화된 지역 인근의 숙소 정보 표기
3. **예약 바로가기 링크:** 네이버 예약, 야놀자, 여기어때 및 전화 예약 바로가기 제공
4. **모바일 관측일지 & 사진 위치 표기:** 현재 위치 또는 촬영한 사진(EXIF GPS) 기반 관측일지 작성 및 저장
