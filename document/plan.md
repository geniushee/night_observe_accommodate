# Plan

## 1. 프로젝트 비전 및 목표
* **프로젝트명:** Starlight Stay (가칭) - 밤하늘 관측 & 청정 숙소 큐레이션 웹 애플리케이션
* **핵심 가치:** 2025 최신 광공해(VIIRS) 지도를 통해 어둡고 맑은 밤하늘 지역을 확인하고, 해당 지역 인근의 숙소를 탐색 및 예약하며, 모바일에서 실시간 위치나 촬영한 사진으로 관측일지를 기록하는 올인원 서비스.

---

## 2. 핵심 요구사항 및 세부 실행 계획

### [1단계] VIIRS 광공해 지도 네이버 지도 오버레이 (완료 ✅)
* **데이터 리소스:** `assets/asia2025.png` (David J. Lorenz 2025 VIIRS 밤하늘 밝기 래스터 데이터)
* **지도 엔진:** 네이버 지도 자바스크립트 API v3 (`naver.maps`)
* **세부 작업:**
  1. [x] `assets/` 디렉토리 구성 및 대한민국 영역 최적화 이미지(`public/assets/korea_lp2025.png`) 전처리 스크립트 작성
     - 좌표계 변환: 정방도법(Plate Carrée, EPSG:4326) $\rightarrow$ 네이버 지도가 사용하는 구면 메르카토르(Web Mercator, EPSG:3857) 정밀 워핑
     - 영역 최적화: 대한민국 전역 (남단 마라도 33.0°N ~ 북단 고성 38.9°N, 서단 백령도 124.5°E ~ 동단 독도 132.0°E)에 맞춰 크롭하여 해외 불필요 영역 배제 및 용량 경량화 (69.4KB)
     - 투명도 처리: 광공해가 없는 칠흑 영역은 완전 투명(Alpha=0), 불빛 영역은 반투명(Alpha=180)
  2. [x] React 컴포넌트(`NaverMap.tsx`) 구현 및 네이버 지도 SDK 동적 로더 연동
  3. [x] `naver.maps.GroundOverlay`를 이용한 광공해 이미지 오버레이 적용 (정확한 `LatLngBounds` 매핑)
  4. [x] 전체 화면(Full Screen) 지도 레이아웃 구현 및 대한민국 외 지역 이동 제한 (`maxBounds`)
  5. [x] 오버레이 On/Off 토글, 실시간 투명도(Opacity) 슬라이더, 지도 타입 전환(일반/위성/지형도), 광공해 등급 범례 패널 UI 제공
  6. [x] NCP Client ID 입력/수정 모달 UI 제공 (LocalStorage 저장 연동)

### [2단계] 숙박 정보 API 연동 및 지도 표기 (완료 ✅)
* **데이터 소스:** 한국관광공사 TourAPI (KorService2 `searchStay2` 및 `searchKeyword2`)
* **세부 작업:**
  1. [x] 한국관광공사 TourAPI와 2025 광공해 래스터(`assets/asia2025.png`)를 대조하여 Bortle 5 이하 숙박/야영 시설 100개 엄선 (`public/assets/bortle5_stays_100.json`)
  2. [x] 주소코드(시군구 Centroid) 기반 1차 필터링 알고리즘 구현 (`src/utils/stayFilter.ts`)
  3. [x] 지도 화면 중심(`map.getCenter()`) 기준 가장 가까운 상위 10개 실시간 선별 및 네이버 커스텀 마커 렌더링
  4. [x] 지도 이동(`idle`) 시 중심에 맞추어 10개 마커 자동 갱신
  5. [x] 마커 클릭 시 인포윈도우(InfoWindow) 표출 및 하단 가로 스크롤 카드 서랍(`NearbyStaysDrawer.tsx`) 연동
  6. [x] 카드 클릭 시 해당 숙소 위치로 부드러운 지도 이동(`map.panTo`) 및 네이버 예약/검색 바로가기 링크 연결

### [3단계] 숙소 예약 사이트 바로가기 링크 연동
* **세부 작업:**
  1. 숙소 상세 팝업 내 주요 예약 플랫폼 바로가기 링크 버튼 구현
     - 네이버 플레이스 / 네이버 예약 바로가기
     - 야놀자 / 여기어때 / 아고다 딥링크 또는 검색 연동
     - 숙소 공식 전화걸기(`tel:`) 및 홈페이지 링크
  2. 사용자가 클릭 한 번으로 예약 화면으로 이동할 수 있도록 직관적인 CTA(Call To Action) 버튼 디자인

### [4단계] 모바일 관측일지 및 사진 기반 위치 표기 기능
* **세부 작업:**
  1. **현재 위치 기반 기록:**
     - HTML5 Geolocation API(`navigator.geolocation`)를 통한 현재 GPS 좌표 수집 및 지도 중심 이동/핀 표기
  2. **촬영 사진 EXIF 기반 위치 추출:**
     - `exifr` 라이브러리를 사용하여 사용자가 업로드한 밤하늘/풍경 사진의 EXIF 메타데이터 자동 파싱
     - 사진에 포함된 GPS 위도/경도, 촬영 일시, 카메라 모델 정보를 추출하여 지도에 전용 카메라 핀 표기
     - GPS 정보가 없는 사진의 경우 현재 위치나 지도 클릭 위치로 핀 지정 기능 제공
  3. **밤하늘 관측일지 작성 및 저장:**
     - 입력 항목: 관측 일시, 관측 장소명, 체감 밤하늘 등급(Bortle Scale 1~9), 관측 대상(은하수, 페르세우스 유성우, 목성/토성 등), 사진, 한줄 메모
     - 데이터 영속성 (초기 단계): 회원가입/로그인 없이 즉시 기록 가능하도록 브라우저 로컬 스토리지(LocalStorage / IndexedDB)에 우선 저장
     - 차후 확장 계획: 별도의 사용자 회원가입 및 중앙 백엔드 서버 구축을 통해 다중 기기 동기화 및 관측일지 커뮤니티 공유 기능으로 발전
     - 일지 리스트 모달/드로어 UI 제공

## 3. 화면 구성 및 UI/UX 구조 (React)

```
[ 상단 네비게이션 / 헤더 ]
- 로고 ("Starlight Stay")
- 레이어 컨트롤 버튼 (광공해 오버레이 On/Off, 투명도 슬라이더)
- 관측일지 작성 버튼 (+)

[ 메인 지도 화면 (네이버 지도) ]
- 광공해 GroundOverlay 래스터 레이어
- 숙박시설 마커 100개 (호버/클릭 시 카드 팝업)
- 내 관측일지 핀 (카메라 아이콘)
- 현재 위치 버튼 (GPS)

[ 플로팅 / 바텀 시트 ]
- 숙소 상세 카드 (사진, 이름, 주변 밤하늘 등급, 예약 링크 바로가기)
- 관측일지 작성 폼 (사진 업로드, EXIF 위치 자동 감지, 후기 메모)
```

## 4. 단계별 마일스톤 및 개발 순서
1. **Milestone 1 (완료 ✅):** `assets/` 폴더 준비, 대한민국 광공해 이미지 가공 및 네이버 지도 기본 연동 + GroundOverlay 구현

4. **Milestone 4:** 모바일 위치 감지, 사진 EXIF 파싱(`exifr`), 관측일지 작성/로컬 저장 기능 구현
